ET portfolio favicon / brand icons

All images are resized directly from ET-original.png (the supplied logo).

- favicon.ico: multi-size browser icon (16, 32, 48)
- favicon-16x16.png, favicon-32x32.png, favicon-48x48.png: browser icon PNGs
- apple-touch-icon.png: 180x180 Apple home-screen icon
- android-chrome-192x192.png, android-chrome-512x512.png: Android/PWA icons
- mstile-150x150.png: legacy Windows tile
- icon-192.png, icon-256.png, icon-512.png: generic icons
- site.webmanifest: basic PWA icon manifest (adjust name and display setting as needed)
- ET-original.png: unchanged input image

Place selected assets in your Next.js public/ directory and configure your site metadata or app manifest as appropriate.
